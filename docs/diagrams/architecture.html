FinanceBench QA Architecture

How the system answers a question about a 10-K, 10-Q, 8-K or earnings report, and how it refuses when it cannot prove the answer. Codes such as A13 or G3 point to entries in docs/assumptions.md and to the 8 guardrails.

  • LLM call
  • Code (deterministic)
  • Data / index
  • Input / output
  • Abstain (no answer)
  • Abstain path
  • Optional / on demand
